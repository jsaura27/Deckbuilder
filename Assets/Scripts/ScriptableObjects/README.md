How to create sample ScriptableObjects (quick)

1. Open Unity Editor.
2. In the Project window, right-click -> Create -> Deckbuilder -> choose the type (CardDefinition, BlessingDefinition, EquipmentDefinition, SkillTreeDefinition, AchievementDefinition).
3. Fill the fields in the inspector (id, displayName, minimal values).
4. Save the asset in `Assets/Content/Samples/` or another clear folder.

Keep these sample SOs tiny: only the fields required by acceptance criteria.
